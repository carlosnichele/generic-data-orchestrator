# Generic Data Orchestrator (Python + SQL)

This repository contains a simplified and fully anonymized version of a data orchestration framework I designed for enterprise environments.

The orchestrator manages:
- ETL pipelines (extract, transform, load)
- Logging and monitoring
- Retry logic
- Config-driven workflows
- Data validation
- SQL-based transformations

All code is generic and does not contain any client-related information.

## Features
- Modular ETL pipeline structure
- Configurable scheduling
- Centralized logging
- Retry with exponential backoff
- Data quality checks
- Database abstraction layer

## Tech Stack
- Python 3.x
- SQL (PostgreSQL syntax)
- YAML for configuration
- Logging module
